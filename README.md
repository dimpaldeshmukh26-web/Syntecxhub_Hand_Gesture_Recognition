# Hand Gesture Recognition

## Project Description
Hand Gesture Recognition is an AI-based project that detects and recognizes hand gestures using a webcam.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy

## Features
- Real-time hand detection
- Open Palm Recognition
- Fist Recognition
- Thumbs Up Recognition

## How to Run
1. Install the required libraries.
2. Keep hand_gesture.py and hand_landmarker.task in the same folder.
3. Open PowerShell in the project folder.
4. Run the following command:

```bash
py hand_gesture.py
```

## Output
The system detects hand gestures through a webcam and displays the recognized gesture on the screen.
